# ☢️ RUST CLONE

**A hardcore multiplayer survival game inspired by Rust.**

Welcome to a brutal world where survival is everything. Gather resources, craft equipment, build your base, fight enemies, and dominate the island.

## 🎮 Features

- 🌲 **Resource Gathering** — Collect wood, stone, metal, and other resources.
- 🏠 **Base Building** — Build shelters and protect your loot from enemies.
- ⚔️ **PvP Combat** — Fight other players and defend your territory.
- 🔫 **Weapons** — Use different weapons to survive and raid enemy bases.
- 📦 **Loot System** — Find valuable items and equipment.
- 👥 **Multiplayer** — Play with friends or compete against other survivors.
- 💀 **Hardcore Survival** — Every decision matters. Trust nobody.

## 🚀 Getting Started

1. Download or clone this repository.
2. Install the required dependencies.
3. Launch the game using the provided instructions.
4. Join the world and start surviving!
