# RUST CLONE — Survival Sandbox

Запусти `RustClone.exe`. Нічого встановлювати не треба.

## Керування
- W A S D — рух, Shift — біг, Ctrl — присісти, Space — стрибок
- ЛКМ — удар / дія, ПКМ — розмістити будівлю
- E — взаємодія, F — їсти/пити, Q — вилучити будівлю
- T — перемикання типу будівлі, Tab — крафт
- R — відродження, Esc — пауза, F10 — вихід

## Збірка
GitHub: Actions → Build EXE → Run workflow, потім завантаж артефакт `RustClone-windows`.
Локально: `build_windows.bat` (CMake + Visual Studio Build Tools).
Іконка: поклади `icon.ico` поруч з `main.cpp`. Шрифт: `font.ttf` поруч з exe (необов'язково).
